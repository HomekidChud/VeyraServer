Features

A browser that runs somewhere else.

Two-minute sessions

Every session starts clean and has a visible countdown. When it hits zero, Veyra deletes the session's cookies, tabs, Chromium context and VPN tunnel on the server.

Real DevTools

Elements with live CSS editing, a console REPL, network waterfall, storage, sources and performance, all working against the proxied page.

Veyra VPN

Send a session through WireGuard, SOCKS5 or HTTP exits. Region pools, failover and a kill switch are handled on the server.

Extensions that act on pages

Dark mode, tracker blocking, reader view, focus mode, zoom, page stats and notes. You can also load your own CSS extension manifests.

Two engines

A fast rewriting proxy for most sites. Heavy apps get a real Chromium tab streamed to you.

Keyboard first

Browser shortcuts work even when the focus is inside a page, and you can rebind every one of them in Settings.

How it works

Three hops, no residue.

  1. You open a site.Veyra creates a session with a two-minute lifetime and a private cookie jar.
  2. Our server fetches it.The page is loaded server-side, optionally through a VPN exit, then rewritten so every link, script and request stays inside Veyra.
  3. The session ends.At 0:00 the server deletes it: cookies, Chromium context, VPN tunnel and crawl jobs. Your browser keeps nothing from the site.

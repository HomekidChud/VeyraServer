# Project structure

| Directory | Responsibility |
| --- | --- |
| `src/` | Production backend modules. |
| `src/browser/` | Proxy, browser-engine, DevTools, page-rewrite, media, and failover modules. |
| `src/config/` | Runtime plan and environment configuration. |
| `src/core/` | Authentication, persistence, sessions, and worker-pool infrastructure. |
| `src/network/` | VPN, request shielding, and device-cast networking. |
| `src/services/` | Search, neural, renewal, branding, and platform services. |
| `src/workers/` | Worker-thread entry points. |
| `scripts/` | Build, setup, operational, and repository validation tools. |
| `tests/legacy/` | Retained legacy regression scripts. |
| `docs/` | Operational and product documentation. |
| `brand/` | Public server-brand assets. |
